# Checklist Audit Alur (Fase 1 revisi, Day 1-2)

Cara pakai: jalani alur sebagai user sungguhan, isi kolom Temuan, beri
prioritas B (blocker: alur terputus/tidak bisa lanjut) atau M (minor:
membingungkan tapi bisa lanjut). Gap blocker diperbaiki duluan (Day 1-3).

## Alur Recruiter (login → keputusan)

| # | Langkah | Yang dicek | Temuan | B/M |
|---|---|---|---|---|
| R1 | Login recruiter | Bisa masuk, role benar | | |
| R2 | Lihat daftar lowongan/FPK | Field requirement (skill/pendidikan/pengalaman) terisi & terstruktur | | |
| R3 | Buka daftar kandidat per lowongan | Kolom skor screening, status stage, flag tampil | | |
| R4 | Buka kandidat ber-flag | Ada daftar review manual, detail skor terlihat | | |
| R5 | Approve/reject di gate | Aksi tersedia, status berubah, tercatat di riwayat | | |
| R6 | Jadwalkan interview | Pilih jadwal → (nanti: link Zoom) → undangan | | |
| R7 | Lihat riwayat stage kandidat | Urutan tahap + waktu + actor terbaca | | |
